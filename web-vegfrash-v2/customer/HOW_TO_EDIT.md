# How to Manage Your Store
**GOOD NEWS!** You no longer need to edit code files to manage your store.

We have built a complete **Admin Dashboard** for you.

## Accessing the Dashboard
1. Go to `http://localhost:3000` (web-store project).
2. Log in with your admin credentials.

## How to specific tasks:

### 1. Add/Edit Products
- Go to the **Products** page in the dashboard.
- Click **Add New Product**.
- To change a price, you can also use the **Stock Ops** page for quick edits.

### 2. Change Categories
- Go to the **Categories** page.
- Add new categories like "Exotic Fruits" or "Spices".
- You can pick the background color for the app cards here.

### 3. Change the Banner
- Go to **Themes / Ads**.
- Change the **Banner Title** text.
- Change the **Banner Gradient** colors.
- The website updates instantly.

### 4. Manage Orders
- Keep the **Live Orders** page open in your store.
- Incoming orders will appear there in real-time.

---
*If you still need to change code-level settings (like the logo or layout), you will need a developer. But for day-to-day operations, the Admin Panel is all you need!*
